Проверка GigaChat через Cloud Function

Текст сообщения безопасно отправляется в вашу Yandex Cloud Function, которая обращается к GigaChat. Ключ GigaChat остаётся только на стороне функции.

Готово к проверке
GigaChat
Здравствуйте! Напишите сообщение — я отвечу через подключённую Cloud Function.

Текущий тестовый режим поддерживает текстовые сообщения. Загрузка и обработка файлов будет добавлена отдельно, когда для неё будет готова серверная обработка.
